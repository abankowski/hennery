# hennery-kernel

Storage, authentication, HTTP kernel and embedded UI for hennery. Part of [hennery](https://github.com/marcinwadon/hennery),
a self-hosted ACP cockpit, licensed under AGPL-3.0-only (see LICENSE).

The internal libraries support the application and have pre-1.0 compatibility;
they are not a separately stable SDK. All seven production crates use one version.

Release packages contain FRONTEND-NOTICES.txt and SOURCE.json. The latter records
the immutable corresponding-source URL, source revision and archive SHA-256 for
the Rust and web sources, lockfiles and build scripts used for this UI.
