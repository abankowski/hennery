## Scope

Let the operator select a local provider redirect while keeping the collector's
public URL, login, passkeys and MCP addresses. Run a small loopback receiver on
the browser's computer. The receiver returns a browser 302 to the fixed collector
callback so its own domain cookie is sent. Tokens never go through the receiver.

## Decisions

- Use an optional per-authorize local_redirect_uri; preserve its bytes exactly.
- Reuse the existing snapshot, exact DCR redirect matching and token exchange.
  No schema change or migration. A manual client remains provider-controlled.
- Share one parsed loopback URL validator between the collector and CLI.
  Resolve localhost to literal IPv4/IPv6 loopback listeners without DNS.
- Keep the helper alive for 900 seconds (configurable), supporting repeated
  Connect/Reconnect, with explicit port errors and timeout. Ctrl+C stops it.
- Use a fixed collector origin argument and preserve the response query verbatim.
  No destination from parameters, no HTTP forwarding to the collector, no logging
  of response parameters, no changes to callback or grant validation.
- First UX: select local, edit exact URL, run displayed shell-quoted command,
  Connect. No helper detection or new trust/configuration machinery.

## Global constraints

Loopback bind only. GET callback only. Every relay response: no-store,
no-referrer, nosniff. Existing state, cookie, issuer, session expiry, one-use,
connection snapshot and grant lock checks remain authoritative. Existing grants
remain usable if a new authorization fails. No deployment or service restart.

+/// Validated local callback. Keep the input verbatim for OAuth's exact match.

+impl LocalCallback {
+    pub fn parse(input: &str) -> Result<Self> {
+        if input.len() > crate::model::MAX_URL || input.chars().any(|c| c.is_control() || c.is_whitespace()) {
+            bail!("invalid local callback URL");
+        }
+        let url = Url::parse(input).map_err(|_| anyhow::anyhow!("invalid local callback URL"))?;
+        let loopback = match url.host() {
+            Some(Host::Domain("localhost")) => true,
+            Some(Host::Ipv4(ip)) => ip.is_loopback(),
+            Some(Host::Ipv6(ip)) => ip.is_loopback(),
+            _ => false,
+        };
+        if url.scheme() != "http"
+            || !loopback
+            || !url.username().is_empty()
+            || url.password().is_some()
+            || url.query().is_some()
+            || url.fragment().is_some()
+            || url.port_or_known_default() == Some(0)
+            || input.contains('\\')
+        {
+            bail!("local callback must be http on localhost or a loopback IP, without credentials, query or fragment");
+        }
+        Ok(Self { url })
+    }
+
+    /// Bind literals only: localhost never goes through DNS or /etc/hosts.
+    /// Both localhost families are served when IPv6 is available.
+    pub async fn bind(&self) -> Result<Vec<tokio::net::TcpListener>> {
+        let port = self.url.port_or_known_default().expect("http has a port");
+        let ips = match self.url.host().expect("validated host") {
+            Host::Domain(_) => vec![IpAddr::V4(Ipv4Addr::LOCALHOST), IpAddr::V6(Ipv6Addr::LOCALHOST)],
+            Host::Ipv4(ip) => vec![IpAddr::V4(ip)],
+            Host::Ipv6(ip) => vec![IpAddr::V6(ip)],
+        };
+        let mut listeners = Vec::new();
+        for ip in ips {
+            match tokio::net::TcpListener::bind(SocketAddr::new(ip, port)).await {
+                Ok(listener) => listeners.push(listener),
+                Err(err) if ip.is_ipv6() && !listeners.is_empty()
+                    && err.kind() == std::io::ErrorKind::AddrNotAvailable => {}
+                Err(err) => return Err(err).context(
+                    "cannot bind local callback: port may be in use; stop the other receiver or choose another callback port in both the UI and CLI"),
+            }
+        }
+        Ok(listeners)
+    }
+
+    /// The destination is fixed before listening; callback input can only
+    /// supply the raw response query. The collector performs all validation.
+    pub fn router(&self, collector: &str) -> Result<Router> {
+        let public = PublicUrl::parse(collector).map_err(|_| anyhow::anyhow!("invalid collector origin"))?;
+        let target = format!("{}{}", public.origin(), crate::api::CALLBACK_PATH);
+        let authority = &self.url[url::Position::BeforeHost..url::Position::AfterPort];
+        Ok(Router::new().fallback(relay).with_state(Relay {
+            path: self.url.path().to_string(),
+            authority: authority.to_string(),
+            target,
+        }))
+    }
+}

+#[derive(Clone)]
+struct Relay {
+    path: String,
+    authority: String,
+    target: String,
+}
+
+async fn relay(State(relay): State<Relay>, request: Request) -> Response {
+    // A fixed Host also refuses DNS rebinding and requests to another local
+    // virtual host. No trace/log middleware: the URI carries credentials.
+    let mut response = if request.uri().path() != relay.path
+        || request.headers().get(header::HOST).and_then(|v| v.to_str().ok()) != Some(relay.authority.as_str())
+    {
+        (StatusCode::NOT_FOUND, "Use the callback address shown by the receiver.").into_response()
+    } else if request.method() != Method::GET {
+        (
+            StatusCode::METHOD_NOT_ALLOWED,
+            "OAuth callback requires browser GET navigation.",
+        )
+            .into_response()
+    } else {
+        let query = request.uri().query().unwrap_or_default();
+        // Copy bytes, including duplicates, unknown keys and encoding. Only
+        // the collector may interpret state, issuer, code and provider errors.
+        let location = format!("{}?{query}", relay.target);
+        match HeaderValue::from_str(&location) {
+            Ok(location) => (StatusCode::FOUND, [(header::LOCATION, location)]).into_response(),
+            Err(_) => (
+                StatusCode::BAD_REQUEST,
+                "Invalid callback response. Start Connect again.",
+            )
+                .into_response(),
+        }
+    };
+    let headers = response.headers_mut();
+    headers.insert(header::CACHE_CONTROL, HeaderValue::from_static("no-store"));
+    headers.insert(header::REFERRER_POLICY, HeaderValue::from_static("no-referrer"));
+    headers.insert(header::X_CONTENT_TYPE_OPTIONS, HeaderValue::from_static("nosniff"));
+    response
+}

+use anyhow::{Result, bail};
+use clap::Args;
+use hennery_gateway::local_callback::LocalCallback;
+use std::time::Duration;
+
+#[derive(Args)]
+pub struct CallbackArgs {
+    /// Fixed collector origin. No destination is read from callback parameters.
+    #[arg(long)]
+    collector: String,
+    /// Exact redirect URI selected in the web UI and permitted by the vendor.
+    #[arg(long, default_value = "http://localhost:8976/callback")]
+    redirect_uri: String,
+    /// Stop listening after this many seconds. Restart before another Connect.
+    #[arg(long, default_value_t = 900, value_parser = clap::value_parser!(u64).range(1..=86400))]
+    timeout_secs: u64,
+}
+
+pub async fn run(args: CallbackArgs) -> Result<()> {
+    let local = LocalCallback::parse(&args.redirect_uri)?;
+    let app = local.router(&args.collector)?;
+    let listeners = local.bind().await?;
+    let mut servers = tokio::task::JoinSet::new();
+    for listener in listeners {
+        let app = app.clone();
+        servers.spawn(async move { axum::serve(listener, app).await });
+    }
+    eprintln!("Local OAuth callback ready at {}", args.redirect_uri);
+    eprintln!("Now click Connect in Hennery in this browser. Keep this terminal open. Ctrl+C stops the receiver.");
+    // Dropping JoinSet aborts every listener on timeout, signal or error.
+    tokio::select! {
+        _ = tokio::time::sleep(Duration::from_secs(args.timeout_secs)) => {
+            bail!("local callback receiver timed out; restart it and click Connect again")
+        }
+        result = tokio::signal::ctrl_c() => { result?; Ok(()) }
+        result = servers.join_next() => {
+            if let Some(result) = result { result??; }
+            bail!("local callback listener stopped; restart it before connecting")
+        }
+    }
