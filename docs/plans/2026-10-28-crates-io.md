UI override and Nix feature contracts remain the starting point. R1 owns global

## Decisions and constraints

- Keep the workspace default private and explicitly opt only the seven-crate
  production closure into crates.io. Paths plus exact registry versions serve
  checkout development and registry consumers. Testkit/pins remain private;
  normalized packages omit repository test harnesses and versionless local dev
  dependencies. Their complete source and fixtures remain in the source archive.
- Move the adapter manifest rather than maintain a second copy. Generator,
  signature/pin CI, docs and Nix read the canonical host package file. Its bytes
  are unchanged by the move; upstream pin verification stays in the pins job.
- Explicit absolute UI override wins, then a validated marked release UI, then
  checkout output. Only unmarked development may use the placeholder. A Cargo
  normalized package (Cargo.toml.orig) cannot lose its marker and silently fall
  back. Inventory checks cover missing/changed/extra/symlinked assets.
- Default source installation builds vendored OpenSSL with a C compiler, make
  and Perl; Nix explicitly disables defaults for dependency/package/clippy
  builds. No Node/pnpm invocation occurs in any Rust build script or install.
- Preparation needs modern Cargo from the flake. Consumption/MSRV is tested
  separately using the 1.88.0 toolchain in scratch RUSTUP_HOME. No global install
  or operator state is used. Never share CARGO_TARGET_DIR between trees.
- Use a loopback sparse test overlay because none of the first seven versions
  exists yet. It is confined to a scratch CARGO_HOME. Prefetch the CLI root as
  well as all dependency packages, then deny OS networking to build/install
  subprocesses. Cargo's publish dry run itself needs HTTP; it remains separate.
- Preserve exact tarballs. Cargo publication repackages, so the publisher uses
  the documented registry API framing over frozen approved bytes. Every
  existing registry version is downloaded/hashed; each dependency's index
  checksum and visibility are checked before consumers. Ambiguous uploads stop.
- The source URL names a release version and full source SHA. R1 must publish
  that exact archive before the kernel channel, bind its digest and retain it
  for AGPL availability. Unauthenticated HTTP status and bytes are checked by
  the publisher. Source inventory proves the complete approved snapshot,
  including web sources, build inputs and fixtures, rather than source maps.
- R1's precise executable/API was not available while this lane was built.
  `packaging/release-gate` is a deliberately absent trusted adapter contract;
  `release` is the proposed protected environment. The parent must reconcile
  these names and authenticate the explicitly separate global/subinventory bindings.
  Setting R3_PUBLISH_ENABLED alone does not provide authorization or credentials.
- Binstall 1.24.0 uses upstream metadata only, correct txz paths and explicit
  GNU-to-musl mappings. It does not automatically verify GitHub attestations.
  Unsigned --only-signed refuses; no binstall signing scheme is claimed.

All actions added here are SHA-pinned, timeout bounded and read-only except the
protected reusable publisher's OIDC permission. No bootstrap secret,
cache restoration, automatic publication trigger or PR artifact promotion exists.

+//! Validates a release package's complete UI inventory before embedding it.
+use serde::Deserialize;
+use sha2::{Digest, Sha256};
+use std::collections::BTreeMap;
+use std::fs;
+use std::path::{Component, Path};
+
+#[derive(Deserialize)]
+#[serde(deny_unknown_fields)]
+struct Inventory {
+    schema: u32,
+    source_sha: String,
+    files: BTreeMap<String, String>,
+}
+
+pub fn validate(root: &Path) -> Result<(), String> {
+    let marker = fs::read(root.join("release-ui.json")).map_err(|e| e.to_string())?;
+    let inventory: Inventory = serde_json::from_slice(&marker).map_err(|e| e.to_string())?;
+    if inventory.schema != 1 || !hex(&inventory.source_sha, 40) || !inventory.files.contains_key("index.html") {
+        return Err("invalid release UI schema, source revision or index.html".into());
+    }
+    for (name, digest) in &inventory.files {
+        if !hex(digest, 64)
+            || name.contains('\\')
+            || Path::new(name).components().any(|c| !matches!(c, Component::Normal(_)))
+            || name.split('/').any(|part| part.starts_with('.'))
+            || name.ends_with(".map")
+        {
+            return Err(format!("invalid release UI entry: {name}"));
+        }
+    }
+    let mut actual = BTreeMap::new();
+    collect(&root.join("web-dist"), &root.join("web-dist"), &mut actual)?;
+    if actual != inventory.files {
+        return Err("release UI files differ from the approved inventory".into());
+    }
+    Ok(())
+}
+
+fn hex(value: &str, len: usize) -> bool {
+    value.len() == len && value.bytes().all(|b| b.is_ascii_digit() || (b'a'..=b'f').contains(&b))
+}
+
+fn collect(root: &Path, dir: &Path, files: &mut BTreeMap<String, String>) -> Result<(), String> {
+    for entry in fs::read_dir(dir).map_err(|e| e.to_string())? {
+        let entry = entry.map_err(|e| e.to_string())?;
+        let path = entry.path();
+        let kind = entry.file_type().map_err(|e| e.to_string())?;
+        if kind.is_symlink() {
+            return Err("release UI contains a symlink".into());
+        }
+        if kind.is_dir() {
+            collect(root, &path, files)?;
+        } else if kind.is_file() {
+            let bytes = fs::read(&path).map_err(|e| e.to_string())?;
+            let name = path.strip_prefix(root).unwrap().to_str().ok_or("non-UTF8 UI path")?;
+            files.insert(name.into(), format!("{:x}", Sha256::digest(bytes)));
+        } else {
+            return Err("release UI contains a non-regular file".into());
+        }
+    }
+    Ok(())
